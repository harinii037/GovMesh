# OPEN THIS FOLDER IN INTELLIJ

This is the corrected single-root Day 1 + Day 2 + Day 3 M5 project.

The folder MUST contain pom.xml directly at its top level.

Next:
1. Open this folder in IntelliJ.
2. Wait for Maven to finish.
3. Open src/main/resources/application.properties.
4. Set PostgreSQL username/password if needed.
5. Run src/main/java/com/govmesh/GovMeshApplication.java.
6. Then test login in Postman.

Do not open a nested project folder. There is only one Maven project in this package.
